# 🎙 دفتر سفارش صوتی فروشگاه

اپلیکیشن تحت‌وب برای ثبت صوتی سفارش‌ها (فارسی/انگلیسی)، تبدیل خودکار گفتار به جدول مرتب‌شونده، و صدور فاکتور.

## قابلیت‌ها
- ضبط صدا و تبدیل گفتار فارسی یا انگلیسی به متن، به‌صورت زنده و پیوسته
- استخراج خودکار از جمله‌ی گفته‌شده: **کالا، سایز، جنس، تعداد، قیمت واحد، قیمت کل**
- جدول قابل مرتب‌سازی با کلیک روی هر ستون (سایز، قیمت، جنس، تعداد و ...)
- امکان ویرایش دستی هر سلول (چون تشخیص گفتار همیشه ۱۰۰٪ دقیق نیست)
- افزودن ردیف دستی، حذف ردیف، محاسبه‌ی خودکار قیمت کل (تعداد × قیمت واحد)
- خروجی CSV/Excel
- صدور و چاپ فاکتور (می‌توانید آن را به‌صورت PDF هم ذخیره کنید)
- ذخیره‌سازی خودکار در همان مرورگر (حتی بعد از بستن صفحه، اطلاعات می‌ماند)
- قابل نصب روی اندروید مثل یک اپ واقعی (PWA)

## جمله‌ی نمونه برای گفتن
> «بگ ۳۰ در ۴۰ سانتی‌متر جنس گلاسه تعداد ۵۰ تا قیمت هر عدد ۳۰۰۰۰ تومان قیمت کل ۱۵۰۰۰۰۰۰ تومان»

کلمات کلیدی که سیستم تشخیص می‌دهد:
- **«عدد در عدد»** → سایز (مثلاً «۳۰ در ۴۰»)
- **«جنس ...»** → نوع جنس
- **«تعداد ...»** یا **«... تا»** → تعداد
- **«هر عدد ...»** یا **«قیمت واحد ...»** → قیمت هر عدد
- **«قیمت کل ...»** → قیمت کل (اگر نگویید، خودش تعداد × قیمت واحد را حساب می‌کند)

اگر جمله دقیق فرمول بالا نباشد هم مشکلی نیست؛ ردیف اضافه می‌شود و شما می‌توانید هر سلول را دستی اصلاح کنید.

## نحوه‌ی اجرا در VS Code (روی کامپیوتر)

1. پوشه‌ی `persian-voice-shop` را در VS Code باز کنید.
2. اکستنشن **Live Server** را از Extensions نصب کنید (اگر ندارید).
3. روی فایل `index.html` راست‌کلیک کنید → **Open with Live Server**.
4. صفحه در مرورگر **Google Chrome** باز می‌شود (حتماً Chrome — تشخیص گفتار در Firefox/Safari محدود یا غیرفعال است).
5. اجازه‌ی دسترسی به میکروفون را بدهید و از «شروع ضبط صدا» استفاده کنید.

> اگر Live Server ندارید، می‌توانید در ترمینال VS Code این دستور را بزنید (نیاز به Node.js دارد):
> ```
> npx serve .
> ```
> و آدرسی که نشان می‌دهد (مثل `http://localhost:3000`) را در Chrome باز کنید.

## نحوه‌ی اجرا روی گوشی اندروید

تشخیص گفتار مرورگر فقط روی آدرس‌های **امن (HTTPS)** یا **localhost** کار می‌کند؛ پس ساده‌ترین و مطمئن‌ترین راه، آپلود رایگان این پوشه روی یک هاست HTTPS است:

### روش پیشنهادی: Netlify Drop (رایگان، بدون نیاز به اکانت گیت‌هاب)
1. وارد سایت `https://app.netlify.com/drop` شوید.
2. کل پوشه‌ی `persian-voice-shop` را با موس بکشید و در صفحه رها کنید (Drag & Drop).
3. یک لینک HTTPS به شما می‌دهد (مثل `https://xxxx.netlify.app`).
4. آن لینک را در **Chrome گوشی اندروید** باز کنید.
5. از منوی سه‌نقطه‌ی بالا سمت راست Chrome گزینه‌ی **«Add to Home screen» / «افزودن به صفحه اصلی»** را بزنید — از این به بعد مثل یک اپ نصب‌شده روی گوشی ظاهر می‌شود و آیکون مخصوص خودش را دارد.

### روش جایگزین: GitHub Pages
اگر با گیت‌هاب راحت‌ترید، همین پوشه را در یک ریپازیتوری آپلود کنید و از تنظیمات ریپازیتوری، GitHub Pages را فعال کنید؛ لینک HTTPS می‌دهد و همان مراحل بالا را انجام دهید.

### نکات مهم
- تشخیص گفتار (Speech-to-Text) از سرویس آنلاین Google استفاده می‌کند، پس گوشی باید به اینترنت وصل باشد.
- فقط در مرورگر **Chrome** (اندروید) به‌طور کامل کار می‌کند.
- اطلاعات جدول فقط داخل همان مرورگر/گوشی ذخیره می‌شود (localStorage)؛ اگر می‌خواهید بین چند دستگاه به‌اشتراک بگذارید، از دکمه‌ی «خروجی CSV/Excel» استفاده کنید.
